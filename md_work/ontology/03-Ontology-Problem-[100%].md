# 3. The Ontology Problem

## 3.1 Current Perception

Users see:
```
Command Center → Economical → Threat & Security → Social Observatory
→ Socio-Political → Environment & Agriculture → Advanced Modeling
```

This is **domain-based navigation**. It fragments intelligence into silos.

## 3.2 Required Perception

Users should see:
```
TIER 1: What is the state of Tunisia?          (Consciousness)
TIER 2: Where is pressure building right now? (Operations)
TIER 3: What happens next?                      (Simulation)
MISSIONS: Follow this threat chain.            (Cross-cutting)
```

This is **mission-based navigation**. It mirrors how intelligence professionals actually think.

## 3.3 The Three Layers

| Layer | Question | Current Modules | Target Tier |
|---|---|---|---|
| **Strategic (State Consciousness)** | "What is happening to Tunisia as a system?" | National Command, Core Intelligence, Governance Matrix, Strategic, Civilizational, Geopolitical, Societal Fracture, Narrative | Tier 1 |
| **Operational (Field Intelligence)** | "Where is pressure building right now?" | Events, Clusters, Security, Radicalisation, Cognitive Warfare, Agriculture, Fire Intel, Industry, Strategic Energy, Black Market | Tier 2 |
| **Simulation (Future Engine)** | "What happens next?" | Simulation, Strategic Modeling, Model Performance, Gov Agent, Historical Patterns, Predictive Charts | Tier 3 |

## 3.4 Why This Matters

Most intelligence platforms stop at monitoring and visualization. TunisiaIntel has moved into **predictive intelligence, synthetic scenario generation, and causal modeling**. But the UI still looks like "many dashboards." Without structural reorganization, complexity will outrun comprehension.
